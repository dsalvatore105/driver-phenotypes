This is the Driver Phenotypes Project, where we will be classifying driving simulator participants into phenotypes based on the data retrieved from the simulation.


## Run the web app

1. Put the drive files in `data/FPP/<participant>/` inside this folder.
2. `pip install -r requirements.txt`
3. `python3 app.py`
4. Open http://localhost:5001

The first load takes about 20 seconds while it clusters all participants.
